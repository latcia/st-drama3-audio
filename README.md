# Drama 3 Cast

SillyTavern 1.18.0+ 多角色配音扩展，当前版本 0.7.2。基于 severian-dev 的 [st-fish-audio](https://github.com/severian-dev/st-fish-audio/tree/ccc2641c9adf651b23f4bfd85b96286427cfbe74)，沿用 MIT 许可证。

## 安装

在酒馆「扩展 → 安装扩展」输入：

```text
https://github.com/latcia/st-drama3-audio
```

安装完成后完整重载酒馆。已安装同名旧插件时，先使用扩展管理中的更新按钮；若旧插件来自其他仓库，需要替换为本仓库。更新前备份酒馆设置，不要删除聊天或服务端音色。

点击悬浮音符打开配音台，也可以在内置 TTS 中选择 `Drama 3 Cast (Local)`。连接页填写自己的 Drama 3 桥接 API 基础地址、合成密钥和独立的音色管理密钥，再点击「保存并测试连接」。

0.7.1 会将两把密钥按 API 地址保存在当前浏览器/App 本机存储，重载和重启后恢复。换回已保存的地址会自动回填；可点「清除此地址的密钥」删除。密钥不进入酒馆设置导出或仓库。清理站点数据、无痕会话结束或卸载 App 后，需要重新填写。浏览器拒绝写入本地存储时会明确提示保存失败。

这个仓库仅提供浏览器前端和世界书，不包含 TTS 引擎、模型、参考音频或服务端凭据。需要一个已运行的兼容桥接服务，直接安装扩展不会启动模型。

## 功能

- 电脑侧边导航、手机顶部导航的中央设置面板，以及带生成和播放状态的悬浮球。
- 点击正文台词下划线，只合成该段。支持选择中英文引号等台词范围。
- 多角色音色匹配、角色别名、默认音色和独立旁白音色。
- 服务端音色预设的读取、创建、修改和参考音频试听，合成请求只提交音色 ID 与台词。
- 分段队列与整场 SSE 流式播放，可设置自动分段提交、提交范围和自动播放。
- `Alt+Shift+D` 手动提交最新回复。中文世界书与日语配音世界书为独立条目，见 `drama3-worldbook.json`。

## 0.7.2 正文识别修复

检查正文及上层容器的显示状态，跳过隐藏副本、思考区域和附属折叠区。Tauri 受管渲染下，台词列表与点读使用宿主提交的同一显示区域，避免面板误读通用节点中的旧内容。没有可读取的显示正文时明确提示，不再回退原文格式化。台词列表标明来源消息编号、字数与段数。引号内部换行不再导致整句漏识别。富文本跨节点无法安全加下划线时，仍可使用台词列表播放。

## 功能说明

- 悬浮球支持鼠标和触摸拖动，位置保存在当前设备，重载后恢复。窗口缩放或横竖屏切换后保持在屏幕内，拖动结束不会误开面板。手机悬浮球缩为 38px，状态提示同步缩小。
- 台词列表、点读、整轮播放和自动提交从实际显示的正文提取内容。已移除、隐藏、代码块、思考区域和附属折叠区不进入朗读队列。未挂载的消息需要先在聊天中显示。原生 TTS 无法定位消息时会提示使用配音台，不读取原文替代。
- 连接、打开面板、回到前台时刷新音色列表，前台每 30 秒检查变化。提供手动刷新和重新载入所选。同步不会自动下载参考音频或覆盖未保存的编辑。
- 服务端版本检查保护多端同时编辑。另一端先保存后，旧页面保存会收到冲突提示，输入仍保留。合成缓存版本与预设元数据版本分开，改显示名和别名不使缓存失效。

安全保存预设需要桥接接口返回 `preset_versioning: 1` 和每个预设的 `metadata_version`；保存时前端携带 `expected_version`，服务端在原子写入前检查，冲突返回 HTTP 409。旧桥接仍可查询和合成，编辑功能会提示升级桥接。此仓库不提供桥接服务端。

## 兼容性

最低客户端要求为 1.18.0，所需 TTS 和格式化接口已按官方 1.18.0 源码核对。单元测试及电脑、手机尺寸浏览器检查已通过，包括鼠标/触摸拖动、位置恢复、隐藏正文过滤、同步和保存冲突；手机真机加载和播放仍待验收。详细依据见 [compatibility.md](compatibility.md)。

## 桥接接口

基础地址下需提供以下接口，并支持 HTTPS、Bearer 密钥、跨域预检与 SSE：

| 接口 | 方法 | 用途 |
| --- | --- | --- |
| `/v1/voices` | GET | 查询音色 |
| `/v1/cast/speech` | POST | 多角色合成，WAV 或 SSE |
| `/v1/voice-presets` | GET、POST | 管理音色预设及参考音频 |

合成和音色管理使用独立权限。密钥仅填入插件连接界面，不写进仓库或 URL。
